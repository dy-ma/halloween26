# Baby's first PCB

A small LED/resistor practice board used to learn KiCad schematic capture, footprints, routing, silkscreen, and Gerber export. It is not the tractor controller and was not intended for manufacture.

Open `babys-first.kicad_pro` in KiCad. This project was originally named `tractor-driver`; the current name reflects its role as a learning exercise. The hardware release script targets only `base-controller/`.
